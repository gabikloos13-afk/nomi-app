# Nomi GitHub PWA

Dieser Ordner enthält die installierbare GitHub-Pages-Hülle für die bestehende
Nomi-App in Google Apps Script.

## Vor dem Upload

In `config.js` die echte Apps-Script-Web-App-Adresse mit `/exec` eintragen.

## GitHub Pages

Repository: `nomi-app`

Veröffentlichung:

```text
Settings → Pages → Deploy from a branch → main → / (root)
```

Adresse:

```text
https://gabikloos13-afk.github.io/nomi-app/
```

Die vollständige Anleitung liegt eine Ebene höher in
`ANLEITUNG_GITHUB_NOMI.md`.
